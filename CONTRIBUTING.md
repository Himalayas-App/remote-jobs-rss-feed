# Contributing

Thanks for helping improve the Himalayas Remote Jobs RSS feed docs and examples.

## What lives here

This repository holds the public documentation and code examples for the RSS
feed. The feed itself is generated by [himalayas.app](https://himalayas.app) and
is not open source.

## Ways to help

- **Report a docs bug.** If the feed's real structure doesn't match what's
  documented here, [open an issue](https://github.com/Himalayas-App/remote-jobs-rss-feed/issues)
  with the element you're looking at and what your parser saw.
- **Add an example in a new language.** Go, Rust, Java, C#, and Elixir are all
  welcome. Match the structure of the existing files in [`examples/`](examples):
  parse the feed, read the `himalayasJobs:` fields, and show how to deduplicate
  on `guid`.
- **Add a feed-reader or automation recipe.** Working setups for Slack, Discord,
  n8n, Make, or Home Assistant are useful additions to the README.

## Ground rules for examples

- **Standard library first.** Only reach for a dependency when the standard
  library genuinely can't do the job.
- **Runnable as-is.** Someone should be able to copy the file and run it with a
  single command, with no API key and no configuration. Accept an optional path
  argument so the example can run against [`sample-feed.xml`](sample-feed.xml)
  offline.
- **Bind the namespaces.** Custom fields live in `https://himalayas.app/ns/jobs`
  and the company logo in `http://search.yahoo.com/mrss/`. Show the reader how
  to register them, not how to string-match tag names.
- **Handle repeated elements.** `locationRestriction` and `timezoneRestriction`
  appear once per value. An empty set means the role is open worldwide.
- **Respect the daily refresh.** The feed rebuilds every 24 hours and advertises
  `ttl=1440`. Don't demonstrate tighter polling.

## Reporting a feed bug

For problems with the feed itself — malformed XML, missing fields, a listing
that shouldn't be there — email [hi@himalayas.app](mailto:hi@himalayas.app) or
open an issue here.
